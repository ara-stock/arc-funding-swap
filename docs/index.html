Funding Swap on Arc

Peer-to-peer fixed-for-floating swaps on Hyperliquid BTC-PERP funding, settled in USDC on Arc mainnet. Lock in a funding rate for a few days, or take the other side, without an intermediary.

Experimental. The contracts are not audited. Margin is capped at 100 USDC per side. The funding index is posted by a single publisher, but it is append-only and anyone can recompute every value from Hyperliquid's public API (rule). If the publisher fails to post the maturity value within 7 days, both sides can reclaim their full margin.
